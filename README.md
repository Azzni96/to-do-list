# To-Do List Application

This is a simple To-Do List application that helps you manage your daily tasks. It allows you to add, update, delete, and filter tasks based on various criteria. You can also export your tasks to different formats like PDF, Excel, and CSV.

## Features

- Add new tasks with a title, priority, and deadline.
- Update and delete existing tasks.
- Mark tasks as done or not done.
- Filter tasks by status (done, not done, all).
- Sort tasks by priority, date, and name.
- Export tasks to PDF, Excel, and CSV.
- Print tasks directly from the browser.
- Toggle between light and dark themes.

## Getting Started

### Prerequisites

- A modern web browser (e.g., Chrome, Firefox, Edge).

### Installation

1. Clone the repository or download the ZIP file.
2. Extract the files to a directory on your computer.

### Usage

1. Open the `index.html` file in your web browser.
2. Use the interface to add, update, delete, and filter tasks.
3. Use the export buttons to download tasks in different formats.
4. Toggle the theme using the theme toggle button.

## Technologies Used

- HTML
- CSS
- JavaScript

## File Structure

- `index.html`: Main page for managing tasks.
- `view.html`: View-only page for tasks.
- `main.js`: JavaScript file containing the logic for managing tasks.
- `style.css`: CSS file for styling the application.
